========================================================
  Hardcore Mario (มาริโอ้เถื่อน) - Standalone Edition
========================================================

[วิธีเล่น]
1. ดับเบิลคลิกที่ไฟล์ 'HardcoreMario.jar' หรือ 'run.bat' เพื่อเริ่มเกมได้ทันที
   (เครื่องต้องมี Java Runtime / JRE 8 ขึ้นไป หรือ JDK)

2. ปุ่มควบคุมในเกม:
   - W, A, S, D  : เดิน / หมอบคลาน
   - SPACE       : กระโดด
   - เมาส์       : เล็งรอบทิศทาง 360 องศา
   - คลิกซ้าย    : ยิงปืน
   - R           : รีโหลดกระสุน
   - C           : สลับสีกระสุน (มีโหมดสำหรับคนตาบอดสี)
   - ESC / P     : เมนูหยุดชั่วคราว (Pause)
   - M           : กลับสู่หน้าหลัก (Main Menu)
   - F1, F2, F3, F4: วาร์ปสลับด่าน 1, 2, 3, 4 ทันที (ด่าน 4 คือบอส Apex Titan)
   - F12         : เปิด/ปิด Debug Mode (Noclip เหาะทะลุฉาก / อมตะ / กระสุนไม่จำกัด)

ผู้พัฒนา: ปฏิพล จันทร์บุญ (6504062636187 ตอน 3)
